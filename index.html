비전 AI 헬스케어

OVERVIEW

요양기관, 비전문 간병인, 가족 보호자를 위한 욕창 고위험 환자의 주기적인 체위 변경(2시간 주기)과 상처 상태 관리를 지원하는 지능형 헬스케어 솔루션입니다.

TECHNOLOGY

Language: JavaScript (ES6+), Python 3.11

AI Engine: MediaPipe Pose Estimation (33개 관절 랜드마크), Vision Classifier

Library: Canvas 2D, ReportLab, Web APIs

Data & Report: NPUAP 4-Stage Classification, 7-Day Care Log (공단평가 규격)

Tool / Deploy: Visual Studio Code, GitHub Pages

KEY RESULTS

  • NPUAP 4단계 표준 가이드: Stage 1~4 단계별 맞춤 드레싱·처치 프로토콜 실시간 연동
  • MediaPipe 33개 관절 좌표: 어깨·골반 30° 측위 기울기 각도 정밀 측정 및 욕창 호발 부위 압력 분산 시각화
  • ReportLab A4 서식 자동화: 모바일 케어 일지와 간호기록지를 매핑한 건보공단 평가 제출용 7일 관리기록지 PDF 원클릭 생성
  • 비전문가 맞춤 UX: 초보 간병인 및 가족 보호자를 위한 스마트 가이드라인 오버레이 UI/UX 구축

머신러닝 시니어 UX

OVERVIEW

가족에게 안부를 전하는 일상적인 글쓰기 과정에서 발생하는 키스트로크(타이핑 리듬)를 활용해 개인의 미세 운동 변화 흐름을 확인하는 생활밀착형 디지털 헬스케어 서비스입니다.

TECHNOLOGY

Frontend: Streamlit, Responsive Web UI (시니어 특화 고대비 UX)

ML Engine: Keystroke Dynamics Analysis (Scikit-Learn, Random Forest)

Key Tech: 타이핑 속도, 키 누름 시간(Hold Time), 키 간격 변동성(Flight Time) 분석

Tool / Deploy: Python, Pandas, NumPy, Streamlit Cloud

KEY RESULTS

  • 행동경제학적 넛지 UX: 검사 거부감 없이 자연스러운 안부 편지 답장 과정에서 타이핑 생체 데이터 자동 수집
